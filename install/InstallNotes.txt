CyoHash 2.6.1 - x64
===================

This installer contains the CyoHash 2.6.1 x64 application and Explorer shell
extension. It requires 64-bit Windows and administrator privileges.

Changes in 2.6.1:
- Results-table dividers align with their column headings.
- Results columns and the results window grow to fit file paths and hashes.
- Hash-detail, file-selection, and forensic metadata dialogs grow with data,
  within the monitor work area; longer content remains scrollable.
- Long detail paths can be selected and copied.
- Executable, About, shell extension, PDF metadata, and installer versions
  have been updated together.

LICENSE.TXT, README.TXT, and BUILD_NOTES_v2.6.1.txt are installed with the app.
Close running CyoHash windows before upgrading. If Explorer has the shell
extension locked, the installer may request a reboot to complete replacement.

For usage, right-click files in Explorer and select a CyoHash algorithm.
Use the menu bar or context menu to export hashes or forensic PDF reports.
Double-click a completed result for hash details and validation.
